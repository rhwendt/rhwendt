## Hi, I'm Ryan 👋

I'm a network automation engineer. Most of what I write is tooling around network devices:
getting data out of them, getting config into them, and keeping track of who logged in.

**Working with:** Go · Python · Ansible · Kubernetes · Prometheus · TACACS+ · Junos / NX-OS / IOS

### Projects

- **[helios](https://github.com/rhwendt/helios)**: network observability on Kubernetes. gNMI and
  SNMP metrics into Prometheus, flow analysis, and dashboards.
- **[enphase-exporter](https://github.com/rhwendt/enphase-exporter)**: Prometheus exporter for the
  Enphase IQ Gateway. Reads the local API, so no cloud account, with per-inverter metrics.
- **[compactor](https://github.com/rhwendt/compactor)**: Claude Code plugin that lets the agent
  hold off auto-compaction during long work and leave itself a note for afterwards.
- **[vaulty](https://github.com/rhwendt/vaulty)**: the Obsidian vault template I use as Claude's
  long-term memory.

I also keep forks of network automation tools I use: NAPALM, NetBox, netpalm, Nautobot ChatOps
and the Cisco NX-OS Ansible collection.
